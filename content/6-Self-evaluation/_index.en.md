During the FCAJ program, I developed QuickBite from a local application baseline into a documented AWS deployment plan. The project gave me opportunities to practice React, FastAPI, PostgreSQL, Docker, IAM, EC2, RDS, S3, CloudFront, CloudWatch, cost control, technical writing, and bilingual reporting.

I also learned that a reliable cloud project is not evaluated only by whether the source code runs. The architecture, permissions, monitoring, testing, cost, clean-up process, and evidence must be explained clearly and consistently.

### Needs Improvement

- Complete the actual AWS deployment and add the final URL, screenshots, logs, and test results.
- Improve discipline in recording screenshots and commit references immediately after each task.
- Make live demonstrations shorter and more focused on the end-to-end customer journey.
- Strengthen production security by moving secrets out of `.env` and adding Infrastructure as Code after the manual deployment is stable.
- Continue improving communication and presentation skills in technical discussions.

### Personal Development Goal

After the program, I want to be able to deliver a small cloud workload through the full lifecycle: requirement analysis, architecture design, deployment, validation, monitoring, troubleshooting, cost control, and resource clean-up.
